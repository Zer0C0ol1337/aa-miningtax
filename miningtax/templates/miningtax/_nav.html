Permissions are read from `perms` rather than passed in by each view, so the bar works wherever it is included without a matching change in Python. Fixed here once, in the file every page already includes, rather than copied into each page separately — a copy-paste version of this exact fix already went missing once this session when a template got rebuilt from an older upload. Scoped to [data-theme="darkly"] — confirmed via the browser's own DOM inspector against a live page (), NOT Bootstrap 5.3's native [data-bs-theme="dark"] mechanism as first assumed: Alliance Auth themes via Bootswatch, a different attribute name and value entirely, which is why an earlier version of this fix silently never matched anything.
